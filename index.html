Google Drive settings

Files upload directly from this browser to the folder you choose. Your OAuth client ID is saved only in this browser.
How to create an OAuth client ID
  1. In Google Cloud Console, enable the Google Drive API.
  2. Create an OAuth 2.0 Web application client.
  3. Add this app's origin to Authorized JavaScript origins.
  4. On the OAuth consent screen, add your Google account under Test users.
  5. Paste the client ID above. No client secret is needed.

Error 403 while testing? Your signed-in Google account must be listed as a Test user for the OAuth app. Changes can take a few minutes to apply.
